# Meridian oracle documents

These files are the **normative oracle** for Waves 7–8 semantics, surface
grammar, integration examples, and hazard review. Tests (`COOK-*`, `SEM_*`,
Composition Gallery) enforce them; this folder is the human-readable source.

| Document | Role |
| --- | --- |
| [MERIDIAN_SEMANTICS.md](MERIDIAN_SEMANTICS.md) | **Meaning** — typed core, trace model, temporal/statistical operators, verbalization law |
| [MERIDIAN_SYNTAX_COOKBOOK.md](MERIDIAN_SYNTAX_COOKBOOK.md) | **Surface** — canonical forms, synonyms, ill-formed catalog, composition gallery |
| [MERIDIAN_NORTHSTAR_EXAMPLE.md](MERIDIAN_NORTHSTAR_EXAMPLE.md) | **Integration** — worked skills, lowering maps, Broken Twin acceptance fixtures |
| [MERIDIAN_DESIGN_RISKS_AND_REVIEW.md](MERIDIAN_DESIGN_RISKS_AND_REVIEW.md) | **Hazards** — amendments, collisions, per-wave exit checklists |
| [INFORM7_DESIGN_NOTES.md](INFORM7_DESIGN_NOTES.md) | **Architecture context** — Inform 7 mechanisms mapped onto Meridian's pipeline |
